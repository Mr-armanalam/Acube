## Phase 0 changes (no behaviour change)

   Rewritten as UTF-8 LF. Removed the literal uploaded-file entry
   `/uploads/2024-08-12T22-09-38.968Z-216696_tiny.mp4`; uploads are now ignored
   as a directory (`uploads/`, `Server/uploads/*`, `apps/api/uploads/*` with
   `.gitkeep` exceptions). Added `apps/*/.env` entries for the Phase 1 layout.
2. **`Server/.gitignore`** — same literal-mp4 entry replaced with `/uploads/*`
   (keeping `!/uploads/.gitkeep`).
3. **`.nvmrc`** — added, `22` (Node 22 LTS target). Baseline was measured on the
   VM's Node v24.22.1; Phase 1 will pin/verify on Node 22.
4. **`.env.example` files (placeholders only — no real secrets):**
   - `Server/.env.example` — all 14 server vars: `DB_URL`, `JWT_SECERT`
     (spelling kept deliberately — see note), `PORT`, `FRONTEND_URL`,

     `STRIPE_SK`, `SECRETKEY_CRYPTO`, `ACCOUNT_SID`, `ACCOUNT_TOKEN`,

     `REACT_APP_CLIENT_ID`, `REACT_APP_ENCRYPTED_KEY`.
   - Total documented: 17 env vars (14 server + 3 client), matching every
     `process.env.*` name found by grep across `client/src` and `Server`.
5. **Dead-code deletions** (verified zero imports/usages by grep before deleting;
   all three files were 100% commented-out duplicates):
   - `client/src/Component/Navbar/ClassNav.jsx` (185 lines)
   - `client/src/Component/videoPlayer/ClassvideoPlayer.jsx` (427 lines)
   - `client/src/Pages/Videopage/ClassLikewatchlaterbtn.jsx` (139 lines)
   - Total removed: ~751 lines of commented-out code. No live component
     imported any of them. The `~1,120` commented lines noted in the audit
     include commented mock-data blocks inside live files; those were NOT
     removed in Phase 0 (removal is only safe file-by-file — left for Phase 2).

- `JWT_SECERT` (misspelled) is kept as-is in code and in `Server/.env.example`,

  `.env` uses the current spelling.
- No dependency, route, or logic change was made in Phase 0.
- `client/build/` and `node_modules/` generated by the baseline runs are
  gitignored and were not committed.
